## 📖 About

**Veritas+** is a gamified digital literacy platform designed to help users distinguish myths from verified facts through interactive learning experiences.

By combining **AI-powered assistance**, **3D learning cards**, **gamification mechanics**, and **knowledge verification**, Veritas+ encourages users to develop stronger critical thinking skills while making learning more engaging and enjoyable.

## ✨ Main Features

### 🗺️ Interactive Learning Path
- 8-level progressive learning journey
- Interactive 3D Flip Cards
- Unlockable learning zones

### 🤖 Veritas AI Assistant
- AI-assisted myth verification
- Instant explanations
- Smart recommendations & Q&A

### ⚡ Quick Quiz
- Random Myth vs Fact challenges
- Score & streak tracking
- Instant feedback

### 📚 Myth Library
- Browse verified myths & facts
- Category filtering
- Reliable educational references

- XP & Level Progression
- Achievement Badges

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/unvariablehuman/Veritas-.git
```

Navigate to the project

```bash
cd Veritas-
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build production

```bash
npm run build
```
